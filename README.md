
# Portfolio Templates (Customizable GSAP Templates)

This repository contains  ready-made, customizable portfolio templates built with modern HTML, CSS and GSAP animation. Use them as a starting point — replace text, assets, fonts and tweak animations to match your brand.


## Notes & tips
- The templates are intentionally minimal and meant as a starting point — remove unused sections, add CMS/back-end integration, or port to React/Next.js as needed.
- If you replace CDN scripts with local packages, update HTML to point to local files or set up a build pipeline (npm, webpack, Vite).
- For production, optimize images, set proper caching headers, and consider inlining critical CSS.
